# PCL Community Edition 

## 项目简介
此PCL CE 是基于 **Plain Craft Launcher 2** 开源代码进行第三次开发的社区版本，包含了官方主线尚未实装的新功能与改进项目。  
请注意：社区版版本号与官方主线并无严格对应关系，也**请勿向官方仓库反馈社区版相关问题**。

- 📦 **社区版下载**：https://github.com/PCL-Community/PCL-CE/releases/latest  
- 📂 **上游仓库**：https://github.com/Meloong-Git/PCL  
- 📖 **文档仓库**：https://github.com/PCL-Community/PCL2CEHelp  

---

## 支持平台

| 操作系统 | 支持情况 | 环境要求 |
|---|---|---|
| Windows 10 1809 及以上 | ✅ 完整支持 | [.NET 8 Desktop Runtime](https://get.dot.net/8) |
| Windows 8 – 1809 | ⚠️ 理论上可运行，有限支持 | [.NET 8 Desktop Runtime](https://get.dot.net/8) |
| Windows 7 及更低版本 | ❌ 不支持 | — |
| macOS / Linux | ⚠️ 仅支持交叉编译 | [.NET 10 SDK](https://get.dot.net/10) |

> 💡 **建议**：始终使用最新版 Windows 与 .NET，以获得最佳体验与完整支持。
